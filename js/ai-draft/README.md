# AI仮情報（ai-draft）

このフォルダの文章は **すべて AI が書いた仮の内容（出典未確認）** です。
アプリ上では、記事・カードに「AI仮情報」のバッジと注意書きが出ます。

## 形式

項目の id（`js/data.js`）をキーにした短い下書きです。

```js
'nail': {
  s: '概要', w: 'なぜ必要か', b: '一般的な基準',
  h: ['手順1', '手順2'], t: '道具', f: '頻度',
  e: '気にしすぎなくていいこと', c: '注意点'
}
```

アプリはここから記事を自動で組み立てます（記事 id は `ai-<項目id>`）。

## 優先順位（差し替えの仕組み）

1. `js/content.js` にその項目を扱う記事（`items` に項目 id を含む）があれば、**そちらが表示され、ai-draft は使われない**
2. 無ければ ai-draft から組み立てた「AI仮情報」の記事を表示
3. どちらも無ければ「記事はまだありません」

## 差し替え方

### 1項目ずつ
`js/content.js` に、出典を確認した記事を追加する（`origin: 'human'`、`status: 'published'`、`sources` に `verified: true`）。
→ その項目の AI仮情報は自動で表示されなくなる。ai-draft 側は消さなくてよい。

### 一気に書き換える
- ファイル単位（`01-05.js` / `06-10.js` / `11-14.js`）で中身をまるごと置き換えてよい。形式さえ同じならアプリ側の変更は不要
- 書き換えて人が確認した内容は、ai-draft ではなく `js/content.js` に移す（ai-draft はあくまで AI仮情報の置き場）
- AI仮情報をまとめて消すなら、`index.html` と `sw.js` の ai-draft の読み込み行を消す（またはファイルを空にする）

### マップのカード（`js/map.js`）
- `origin: 'ai'`（ファイル先頭）が全カードの既定値
- 確認したカードに `origin: 'verified'` を付けると、そのカードの AI仮情報表示が消える
- 全部確認し終えたら、先頭の `origin` を `'verified'` に変える

## 進み具合の確認

```sh
node tools/ai-report.js          # 件数
node tools/ai-report.js --list   # 残っている項目の一覧
```
