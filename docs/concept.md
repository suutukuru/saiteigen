# アプリのコンセプト・基本方針

> 「知らなかったことを、今から学ぶ。」
> 「できなかったことを、できるようにする。」
> **「普通にできるようになる。そして、格好よくなる。」**

## 1. アプリの目的

大人になる過程で自然に身につける機会があったはずの知識や習慣を、今から体系的に学び、実践できるようにするアプリ。

身だしなみ、清潔感、ファッション、生活管理、社会的な振る舞い、コミュニケーション、店選び、プレゼント選びなど、日常生活や人付き合いの中で必要となる幅広い知識を扱う。

単に知識を提供するだけではなく、自分に何が足りないのかを発見し、何を改善すればよいのかを理解し、実際に行動できるようになることを目指す。

## 2. 解決したい課題

家庭環境や友人関係、学校生活、職場、日常経験などを通じて自然に身につけていく知識や習慣があるが、誰もが同じように学ぶ機会を得られるわけではない。

- 何をすれば清潔感のある状態になるのか分からない
- 髪型や眉毛、髭など、身だしなみの整え方を知らない
- 服装やファッションの基本が分からない
- 洗濯や掃除、日用品の管理方法が分からない
- 自分の体臭や衣類の臭いなど、気にするべきポイントが分からない
- 飲食店や遊びに行く場所の選び方が分からない
- プレゼントを選ぶときの一般的な考え方が分からない
- 食事のマナーや人との接し方に自信がない
- コミュニケーションにおいて、何を意識すればよいのか分からない
- 周囲の人が自然にできていることを、自分だけ知らないと感じる
- 今さら人に聞くのが恥ずかしく、学ぶ機会を逃してしまう

こうした知識は**知らないこと自体に気づきにくい**。そのため、利用者が自分で検索するだけでなく、**アプリ側から改善ポイントや学習項目を提示する**仕組みが必要。

## 3. アプリが目指す状態

1. 社会生活における基本的な知識や習慣が身についている
2. 清潔感があり、身だしなみが整っている
3. 自分に合った服装や髪型、持ち物を選べる
4. 日常生活に必要な家事や管理ができる
5. 店選びやプレゼント選びなど、一般的な判断基準を理解している
6. 人と接するときの基本的なマナーや振る舞いを身につけている
7. 自分に不足している部分を把握し、自分で改善できる
8. 自分に自信を持ち、より魅力的な人間を目指せる

## 5. 基本的な機能

1. **知識データベース**：概要／なぜ必要なのか／一般的な基準／推奨される方法／具体的な手順／必要な道具や商品／選び方／注意点／実施頻度／維持管理方法／参考情報・情報源
2. **自己診断・改善ポイントの発見**：自分では気づいていない不足を発見する
3. **おすすめ・改善提案**：改善内容／理由／優先順位／方法／時間／費用／期待できる効果
4. **学習・実践状況の管理**：知らない → 知っている → 学習中 → 実践待ち → 実践中 → 習慣化 → 維持管理
5. **習慣・タスク管理**：毎日／毎週／毎月／季節ごと／必要に応じて
6. **持ち物・メンテナンス管理**：状態・手入れ・買い替え時期
7. **欲しいもの・購入計画**：予算・優先順位・購入予定日

## 6. 情報の信頼性

次を区別して掲載する：公的機関の情報／学術的・科学的根拠／専門家の推奨／メーカーの公式情報／一般的な慣習／トレンド／個人の好みや主観。

- 情報源・確認日・更新履歴を管理し、根拠が不十分な情報を断定的に掲載しない
- 医学的な内容は診断や治療を目的とせず、必要に応じて専門家への相談を案内する
- 商品紹介を目的化せず、まず知識や判断基準を提供し、その後に必要な商品を紹介する

## 7. 設計思想

- **初心者を前提とする**：誰もが知っていると思われることでも基礎から説明する
- **恥ずかしさを感じずに学べる**：年齢に関係なく、初めて知ることを自然に学べる
- **自分では気づかない不足を発見できる**：アプリから学ぶべき項目を提示する
- **一般的な基準を理解できる**：何が基本で、どの程度まで整えるべきかを具体的に説明する
- **実践につなげる**：読んで終わらせず、行動や習慣に結びつける
- **自分に合った選択ができる**：一般的な基準を理解したうえで、好みや状況に応じて選べる
- **改善の必要がないことも理解できる**：必要以上に気にしたり完璧を目指したりしないよう、一般的な許容範囲や個人差も説明する

## 8. 最終的な目標

知らなかったことを学び、できなかったことをできるようにし、不足している部分を一つずつ改善できるようにする。

清潔感があり、身だしなみが整い、日常生活の基本ができ、周囲の人や状況に応じた判断ができる。そして、自分に自信を持ち、より魅力的な人間になれること。
