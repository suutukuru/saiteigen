# さいていげん — 大人の身だしなみ・生活力向上アプリ

大人になる過程で自然に身につけるはずだった知識を、今から体系的に学び、実践・継続できるようにするアプリです。
「何をすればいいか分からない人に、何を気にすればいいかを教える」ことを核にしています。

## まずは iPhone の「ファイル」で使う（公開しない）

公開せず、端末内だけで使う方法です。`dist/saiteigen.html` は CSS・JS・アイコンを全部埋め込んだ **1ファイル版** です。

1. GitHub アプリ / Working Copy などで `dist/saiteigen.html` を「ファイル」アプリに保存する
2. **「ファイル」のプレビュー（Quick Look）では動かないことがあります。** HTML を開けるアプリ（Documents by Readdle など）や、共有メニューの「Safari で開く」系で開いてください
3. 開き方によっては、**記録がブラウザに保存されない／次回消えることがあります**。その場合は起動時に警告が出ます。こまめに「マイページ → バックアップを書き出す」を使ってください
4. 動作確認はパソコン上のブラウザでのみ済ませています。実機の iPhone では環境により挙動が違う可能性があります

内容を変えたら、単一HTMLを作り直します（パソコンまたは Claude Code で）:

```sh
node tools/build-single.js
```

### 将来アプリとして公開するための準備（残してあります）

- PWA 一式：`manifest.webmanifest`、`sw.js`（オフライン）、`icons/`（180/192/512px と SVG）
- 複数ファイル構成（`index.html` + `css/` + `js/`）なので、GitHub Pages や任意の静的ホスティングにそのまま置けます
- データ・コンテンツ・画面が分離されているため、将来 App Store 向けに包む場合（Capacitor 等）も `js/` を流用できます
- 記録は `localStorage` の `saiteigen.v1` に JSON で保存。バックアップ形式がそのままデータ移行に使えます

## 公開して使う場合（iPhone だけで開発する）

ビルド不要の静的 Web アプリ（PWA）です。サーバーもアカウントも要りません。
記録はすべて **その iPhone のブラウザ内（localStorage）** に保存され、外部には送信されません。

### 1. 公開する（最初の一回だけ・iPhone の Safari で可）

1. GitHub のリポジトリページ → **Settings** → **Pages**
2. Source を **Deploy from a branch**、Branch をこのアプリのあるブランチ（例 `main`）・フォルダを `/ (root)` にして Save
3. 1〜2分後、`https://<ユーザー名>.github.io/saiteigen/` で開けます

> リポジトリが非公開の場合、GitHub Pages は有料プランが必要です。無料で使うならリポジトリを公開にしてください（記録データはリポジトリに含まれないので、公開しても個人の記録は漏れません）。

### 2. ホーム画面に追加する

1. Safari で上の URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. 以降はアプリのように全画面で起動し、**オフラインでも動きます**（Service Worker でキャッシュ）

### 3. データのバックアップ

マイページ →「バックアップを書き出す」で JSON ファイルを「ファイル」アプリなどに保存できます。
機種変更や Safari のデータ削除の前に書き出し、「バックアップから復元」で戻せます。

### 4. iPhone で中身を編集する

- GitHub アプリ / Safari の github.com、または Working Copy などの Git アプリでファイルを直接編集できます
- 編集してコミットすると、数分で GitHub Pages に反映されます
- **反映後にアプリへ確実に届けるため、`sw.js` の `VERSION` と `index.html` の `SAITEIGEN_VERSION` を上げてください**
- ホーム画面アプリは起動時に最新を取得し、取得できないとき（オフライン）はキャッシュで動きます

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の土台・タブバー |
| `css/style.css` | 見た目（ライト／ダーク対応） |
| `js/data.js` | 13カテゴリー・項目・観点・自己チェック・おすすめ・習慣ひな型 |
| `js/content.js` | 知識コンテンツ（出典・最終確認日・更新履歴付き） |
| `js/app.js` | アプリ本体（画面・記録・習慣・持ち物・欲しいもの・バックアップ） |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応・ホーム画面アイコン |

## 項目やコンテンツを増やす

- **項目**：`js/data.js` の各カテゴリーの `items` に `I('一意のid', '項目名', { viewpoint, checks, suggest, tasks, articles })` を追加
  - `id` は記録と紐付くため、**一度公開したら変更・再利用しない**
- **記事**：`js/content.js` に追加し、項目の `articles` に記事 id を書く
  - 本文の段落ごとに `basis`（`official` 公的 / `science` 科学的根拠 / `expert` 専門家 / `custom` 慣習 / `trend` トレンド / `preference` 好み / `uncertain` 不確実）を付けて、事実と好みを区別する
  - 出典は `sources` に入れ、主張を裏付けていることを確認したら `verified: true` と `checkedAt` を記入
  - 確認が終わるまで `status: 'draft'`（画面に「下書き・出典確認前」と出ます）。確認後 `published`、非公開にするなら `archived`
  - 変更したら `history` に日付とメモを追加

> 同梱の記事5本は**動作確認用の下書き**です。要件定義のとおり、AI が書いた文章をそのまま公開扱いにせず、出典の確認と編集者のレビューを経てから `published` にしてください。
